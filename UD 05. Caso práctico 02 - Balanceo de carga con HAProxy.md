




# Caso Práctico: Balanceo de Carga con HAProxy y Docker
## Autor: Elías Legidos 2ASIR 
Este proyecto implementa un sistema de balanceo de carga utilizando un contenedor **HAProxy** que reparte el tráfico entre dos servidores **Apache** independientes



## 1. Construcción de Imágenes
Antes de lanzar los contenedores, es necesario construir las imágenes locales desde sus respectivos directorios

**Servidor Apache 01**: `cd apache01 && docker build -t miapache01 .` 
**Servidor Apache 02**: `cd apache02 && docker build -t miapache02 .` 
**Balanceador HAProxy**: `cd haproxy && docker build -t mihaproxy .` 

> **Nota:** La imagen de HAProxy se basa en `haproxy:1.7` y copia un archivo de configuración personalizado.

## 2. Configuración de la Red
Se requiere una red común para que los contenedores se comuniquen por nombre de host:

```bash
docker network create balanceo
``` 

## 3. Despliegue de Contenedores

### Paso A: Servidores Backend (Apache)
Lanzamos los dos servidores que atenderán las peticiones:

```bash
docker run -d --name ap01 --network balanceo miapache01
docker run -d --name ap02 --network balanceo miapache02
``` 

### Paso B: Balanceador (HAProxy)
Lanzamos el balanceador mapeando el puerto **8080** del anfitrión al **80** del contenedor[cite: 254]. [cite_start]Usamos variables de entorno para configurar las IPs de los servidores:

```bash
docker run -d --name ha01 --network balanceo -p 8080:80 \
  -e APACHE_1_IP=ap01 \
  -e APACHE_2_IP=ap02 \
  -e APACHE_EXPOSED_PORT=80 \
  mihaproxy
``` 

## 4. Verificación del Balanceo
1. Abre tu navegador en `http://localhost:8080`.
2. Verás el mensaje: *"Servido por: Servidor Apache 01"*.
3. Al recargar la página (o usar `CTRL + F5`), el mensaje cambiará a: *"Servido por: Servidor Apache 02"*.

---

## 5. Opcional: Uso de Volumen Común
Para que ambos servidores compartan el mismo contenido HTML:

1. **Crear imagen de volumen**: `cd apachevolumen && docker build -t miapachevolumen .` 
2. **Eliminar contenedores anteriores**: `docker stop ap01 ap02 && docker rm ap01 ap02` 
3. **Lanzar con volumen compartido**:
   ```bash
   # Primer servidor (puebla el volumen)
   docker run -d --name ap01 --network balanceo -v datosapache:/usr/local/apache2/htdocs/ miapachevolumen
   
   # Segundo servidor (usa el volumen ya creado)
   docker run -d --name ap02 --network balanceo -v datosapache:/usr/local/apache2/htdocs/ httpd:2.4
  ```
