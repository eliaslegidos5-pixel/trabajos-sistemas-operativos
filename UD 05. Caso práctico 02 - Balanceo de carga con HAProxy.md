




# Caso Práctico: Balanceo de Carga con HAProxy y Docker
## Autor: Elías Legidos 2ASIR 
[cite_start]Este proyecto implementa un sistema de balanceo de carga utilizando un contenedor **HAProxy** que reparte el tráfico entre dos servidores **Apache** independientes[cite: 176].



## 1. Construcción de Imágenes
[cite_start]Antes de lanzar los contenedores, es necesario construir las imágenes locales desde sus respectivos directorios[cite: 181, 188]:

* [cite_start]**Servidor Apache 01**: `cd apache01 && docker build -t miapache01 .` [cite: 182, 183]
* [cite_start]**Servidor Apache 02**: `cd apache02 && docker build -t miapache02 .` [cite: 184, 185]
* [cite_start]**Balanceador HAProxy**: `cd haproxy && docker build -t mihaproxy .` [cite: 186, 187]

> [cite_start]**Nota:** La imagen de HAProxy se basa en `haproxy:1.7` y copia un archivo de configuración personalizado[cite: 205, 207].

## 2. Configuración de la Red
[cite_start]Se requiere una red común para que los contenedores se comuniquen por nombre de host[cite: 247]:

```bash
docker network create balanceo
[cite_start]``` [cite: 248]

## 3. Despliegue de Contenedores

### Paso A: Servidores Backend (Apache)
[cite_start]Lanzamos los dos servidores que atenderán las peticiones[cite: 249]:

```bash
docker run -d --name ap01 --network balanceo miapache01
docker run -d --name ap02 --network balanceo miapache02
[cite_start]``` [cite: 251, 252]

### Paso B: Balanceador (HAProxy)
[cite_start]Lanzamos el balanceador mapeando el puerto **8080** del anfitrión al **80** del contenedor[cite: 254]. [cite_start]Usamos variables de entorno para configurar las IPs de los servidores[cite: 256, 257]:

```bash
docker run -d --name ha01 --network balanceo -p 8080:80 \
  -e APACHE_1_IP=ap01 \
  -e APACHE_2_IP=ap02 \
  -e APACHE_EXPOSED_PORT=80 \
  mihaproxy
[cite_start]``` [cite: 256]

## 4. Verificación del Balanceo
1. [cite_start]Abre tu navegador en `http://localhost:8080`[cite: 258].
2. [cite_start]Verás el mensaje: *"Servido por: Servidor Apache 01"*[cite: 268].
3. [cite_start]Al recargar la página (o usar `CTRL + F5`), el mensaje cambiará a: *"Servido por: Servidor Apache 02"*[cite: 273, 275].

---

## 5. Opcional: Uso de Volumen Común
[cite_start]Para que ambos servidores compartan el mismo contenido HTML[cite: 279]:

1. [cite_start]**Crear imagen de volumen**: `cd apachevolumen && docker build -t miapachevolumen .` [cite: 281, 282]
2. [cite_start]**Eliminar contenedores anteriores**: `docker stop ap01 ap02 && docker rm ap01 ap02` [cite: 284, 285]
3. **Lanzar con volumen compartido**:
   ```bash
   # Primer servidor (puebla el volumen)
   docker run -d --name ap01 --network balanceo -v datosapache:/usr/local/apache2/htdocs/ miapachevolumen
   
   # Segundo servidor (usa el volumen ya creado)
   docker run -d --name ap02 --network balanceo -v datosapache:/usr/local/apache2/htdocs/ httpd:2.4
   [cite_start]``` [cite: 287, 296, 297]
